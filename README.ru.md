### 1. 📊 [Высокопроизводительный интерактивный таймлайн / шахматка](https://github.com/G1glz/название-репозитория-1)

**Стек:** _React Native, React Native Skia, Reanimated v3, Feature-Sliced Design (FSD)_
Проект демонстрирует обход бутылочного горлышка React (избыточные ререндеры с накладными расходами $O(N)$) при работе со сложными, динамически меняющимися интерфейсами (календарные сетки, шахматки бронирования, интерактивные графики).

- **GPU-Ускорение:** Полный отказ от тяжелых нативных View-иерархий React в пользу отрисовки всего графа элементов на едином холсте Skia Canvas.
- **Zero Main-Thread Load:** Обработка жестов в реальном времени (Hit-Testing для Drag-and-Drop, изменения размеров и разбиения блоков) полностью вынесена в UI-поток рантайма через **Reanimated Worklets**.
- **Динамические графы:** Рендеринг «резиновых» линий связи между карточками с использованием кривых Безье (`Skia.Path.Make() / cubicTo`), плавно пересчитывающихся на GPU со стабильными 60/120 FPS прямо во время перетаскивания.

### 2. 🛡️ [Zero-Trust Upload Pipeline и движок асинхронного логирования](https://github.com/G1glz/название-репозитория-2)

**Стек:** _Node.js / TypeScript, Redis (Очереди), ClickHouse, Docker_
Микросервис бэкенда, реализующий стратегии глубокой защиты от критических уязвимостей **OWASP Top 10 (Arbitrary File Upload и RCE)** в сочетании с высокопроизводительным конвейером асинхронного аудита.

- **Защита от RCE и инъекций:** Потоковая валидация файлов по реальным сигнатурам (Magic Bytes) на лету, обфускация имен сохраняемых файлов и абсолютная изоляция прав в файловой системе.
- **Асинхронный конвейер:** Вынос ресурсоемких задач сканирования безопасности из цикла «запрос-ответ» в воркеры на базе **очередей Redis** для обеспечения мгновенного ответа клиенту.
- **Высокоэффективный аудит:** Паттерн пакетной вставки (Bulk Insert) сетевых логов и векторов атак в колоночную БД **ClickHouse** для предотвращения троттлинга дисковой подсистемы (I/O) при высоких нагрузках.
